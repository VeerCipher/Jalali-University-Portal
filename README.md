# JALALI University Portal 

A menu-driven University Management Portal developed using the C programming language as a lab mid project.

## Features

### Student Portal
- Student login authentication
- View attendance
- View marks and grades
- Course content
- Assignments
- Programming quiz
- Class timetable
- Faculty details
- Project information

### Faculty Portal
- Faculty login authentication
- View all student records
- Update student marks
- Manage attendance
- Access course content and assignments
- View quizzes and timetable
- Student reports
- HR information
- Portal settings

## Technologies Used

- C Programming
- Dev-C++ IDE

## Concepts Implemented

- Structures (`struct`)
- Arrays
- Functions
- `while` loops
- `if-else` statements
- `switch` statements
- String handling
- Login authentication
